# IDX Style Web App - Design Guide

## Design Philosophy

### Color Palette
- **Primary**: Deep charcoal (#2C3E50) for headers and navigation
- **Secondary**: Warm taupe (#8B7355) for accents and CTAs
- **Neutral**: Soft ivory (#FEFEFE) for backgrounds
- **Accent**: Muted sage (#7A8471) for highlights and interactive elements

### Typography
- **Display Font**: Tiempos Headline (serif) for property titles and headings
- **Body Font**: Suisse Int'l (sans-serif) for descriptions and interface text
- **UI Font**: Inter (sans-serif) for forms and navigation elements

### Visual Language
- **Minimalist Aesthetics**: Clean lines, ample white space, and purposeful design
- **Editorial Sophistication**: Inspired by high-end real estate publications
- **Data-Driven Focus**: Emphasis on clear information hierarchy and scannable content
- **Professional Trust**: Sophisticated color palette and premium typography

## Visual Effects & Animations

### Core Libraries Used
- **Anime.js**: Smooth property card animations and page transitions
- **ECharts.js**: Interactive market data visualizations and price trends
- **Splide.js**: Property image carousels and featured listings slider
- **p5.js**: Dynamic background patterns and interactive map elements
- **Pixi.js**: Advanced visual effects for hero sections
- **Matter.js**: Physics-based interactions for property comparison tool

### Animation Patterns
- **Subtle Reveal**: Property cards fade in with staggered timing as user scrolls
- **Hover Depth**: Cards lift with shadow expansion and subtle scale transform
- **Loading States**: Skeleton screens with shimmer effects during data fetching
- **Micro-interactions**: Button hover states with color transitions and gentle scaling

### Header Effects
- **Gradient Flow**: Subtle animated gradient background using CSS and Anime.js
- **Parallax Elements**: Background images move at different speeds during scroll
- **Typewriter Animation**: Property headlines appear with typing effect

### Background Styling
- **Consistent Base**: Soft ivory (#FEFEFE) maintained throughout all pages
- **Texture Overlay**: Subtle paper-like texture for editorial feel
- **Geometric Accents**: Minimal line patterns in corners using p5.js
- **No Gradients**: Solid colors only, maintaining clean aesthetic

### Interactive Elements
- **Filter Animations**: Smooth transitions when applying search filters
- **Map Interactions**: Hover effects on property markers with info popups
- **Image Galleries**: Ken Burns effect on property photos with smooth transitions
- **Data Visualization**: Animated charts showing market trends and statistics
