# PropertyScope - Premium Real Estate Platform

A sophisticated IDX-style web application for property search and discovery, built with modern web technologies and featuring premium design aesthetics.

## 🏠 Features

### Core Functionality
- **Advanced Property Search**: Multi-criteria filtering with real-time results
- **Interactive Property Listings**: Grid view with hover effects and infinite scroll
- **Detailed Property Pages**: Comprehensive information with image galleries
- **Mortgage Calculator**: Interactive payment estimation tool
- **Interactive Maps**: Property locations with nearby amenities using Leaflet.js
- **Market Analytics**: Price trends and market insights with ECharts.js

### Design & UX
- **Premium Aesthetics**: Modern editorial design with sophisticated color palette
- **Responsive Design**: Mobile-first approach with seamless cross-device experience
- **Smooth Animations**: Powered by Anime.js for engaging user interactions
- **Professional Visuals**: High-quality property photography and custom-generated imagery

### Technical Stack
- **Frontend**: HTML5, CSS3 (Tailwind CSS), JavaScript (ES6+)
- **Animations**: Anime.js for smooth transitions and micro-interactions
- **Data Visualization**: ECharts.js for market trend charts
- **Image Carousels**: Splide.js for property galleries
- **Maps**: Leaflet.js for interactive property locations
- **Typography**: Inter font family for clean, professional text

## 📱 Pages

1. **Landing Page** (`index.html`)
   - Hero section with search interface
   - Featured property listings
   - Market statistics and price trends
   - Quick category filters

2. **Property Details** (`property-details.html`)
   - Comprehensive property information
   - Image gallery with thumbnail navigation
   - Interactive mortgage calculator
   - Contact agent form
   - Location map with nearby amenities
   - Similar properties recommendations

3. **Advanced Search** (`search.html`)
   - Comprehensive filtering system
   - Price range sliders
   - Property feature checkboxes
   - Map/list view toggle
   - Sort and pagination options

## 🎨 Design Philosophy

The platform follows a modern editorial aesthetic inspired by high-end real estate publications:
- **Color Palette**: Deep charcoal, warm taupe, soft ivory, and muted sage
- **Typography**: Clean Inter font family for optimal readability
- **Visual Language**: Minimalist design with purposeful white space
- **Interactions**: Subtle animations that enhance rather than distract

## 🚀 Performance

- Optimized for fast loading with lazy loading images
- Smooth 60fps animations using transform and opacity
- Responsive design optimized for all screen sizes
- Progressive enhancement for JavaScript features

## 📊 Interactive Features

- **Real-time Search**: Instant filtering as users type
- **Property Comparison**: Side-by-side feature comparison
- **Market Analytics**: Interactive charts showing price trends
- **Mortgage Calculator**: Dynamic payment calculations
- **Map Integration**: Property markers with popup information

## 🔧 Setup

The application is built as a static site and can be deployed to any web server:

```bash
# Local development
python -m http.server 8000

# Open in browser
http://localhost:8000
```
